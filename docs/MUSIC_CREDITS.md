## 为什么《魔王》可以用，而《蔚蓝档案》的曲子不能用

| | 《魔王》 | 蔚蓝档案 |
|---|---|---|
| 作曲者 | 舒伯特（1828 年逝世）| 在世作曲家，公司运营中 |
| 版权状态 | **公有领域** | **受保护** |
| 官方二创协议 | 不需要 | 明文**禁止商用** |
| 结论 | ✅ 可用 | ❌ 不可用 |

**判断标准始终是：作品是否还在版权保护期内。** 而不是"有没有二创协议"。
