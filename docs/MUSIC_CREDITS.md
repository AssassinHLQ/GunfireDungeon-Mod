## 为什么《魔王》可以用，而《蔚蓝档案》的曲子不能用

| | 《魔王》 | 蔚蓝档案 |
|---|---|---|
| 作曲者 | 舒伯特（1828 年逝世）| 在世作曲家，公司运营中 |
| 版权状态 | **公有领域** | **受保护** |
| 官方二创协议 | 不需要 | 明文**禁止商用** |
| 结论 | ✅ 可用 | ❌ 不可用 |

**判断标准始终是：作品是否还在版权保护期内。** 而不是"有没有二创协议"。

## 版本说明：小提琴版

新增文件：`魔王_钢琴版/魔王_完整版_加小提琴.wav` / `.ogg`

### 小提琴旋律是从哪来的

**不是新写的，是原曲本来就有的那条旋律线。**

原始 MIDI 有 4 条轨：

| 轨 | 内容 | 音符数 | 时间范围 |
|---|---|---|---|
| 0 | 控制轨（无音符）| — | — |
| **1** | **主旋律（声乐）** | **337** | **第 23.3 ~ 235.9 秒** |
| 2 | 钢琴右手 | 4145 | 第 0 ~ 238.1 秒 |
| 3 | 钢琴左手 | 1085 | 第 1.6 ~ 238.1 秒 |

轨 1 原本用**多种音色**（小号 / 巴松 / 口琴 / 排笛 / 长号）区分《魔王》里的
**四个角色**（叙述者 / 父亲 / 儿子 / 魔王）——这是舒伯特这首叙事歌的写法。

**本版把轨 1 的音色统一改成小提琴（GM program 40）**，得到一条完整的独奏旋律线。

### 混音方式

| 时间 | 内容 |
|---|---|
| 0 ~ 50 秒 | 纯钢琴 |
| 50 秒起 | 小提琴主旋律淡入（3 秒淡入）|

### 客观验证（小提琴确实加进去了）

对比加之前/之后在同一段落的频谱能量：

| 时间段 | 频段 | 变化 |
|---|---|---|
| 50-70 秒 | 2000-4000 Hz | **+1.8 dB** |
| 50-70 秒 | 4000-10000 Hz | **+1.8 dB** |
| **150-170 秒（副歌）** | 2000-4000 Hz | **+5.1 dB** |
| **150-170 秒** | 4000-10000 Hz | **+4.3 dB** |

小提琴的泛音正落在 2000-10000 Hz，该区间被明显提升；钢琴主导的低频段几乎不变。

进入瞬间的能量跳升：47-50 秒 RMS 0.0983 → 53-56 秒 RMS 0.1301（**+32%**）。

### 混音技术要点（踩过的坑）

1. **采样率必须匹配** —— 已有的钢琴渲染是 **44100Hz 单声道**，
   小提琴一开始渲染成了 48000Hz 立体声，直接相加会把 242 秒的曲子变成 225 秒、音高全错
2. **钢琴本身峰值就到 0.89，没有余量** —— 直接叠加必然削波，结果只能把小提琴压到很小。
   正确做法是**先把钢琴降到 62% 腾出余量**，混完再把整条归一化回去
3. **小提琴原始电平比钢琴低 18 dB** —— 靠猜增益没用，要按测量值归一化
