# 开发环境搭建（换电脑用）

> 目标：在一台**全新的电脑**上把这个项目跑起来。
> 本文按 2026-09-24 的仓库实际状态写，不是通用模板。

---

## 一、必装

| # | 软件 | 版本 | 为什么 |
|---|---|---|---|
| 1 | **Git** | 任意较新版本 | 拉仓库 |
| 2 | **.NET SDK** | **9.0**（不是 runtime！）| 本项目 `TargetFramework = net9.0` |
| 3 | **Godot** | **4.7.1 .NET 版** | 工程里钉死了 `Godot.NET.Sdk/4.7.1` |

### 1. Git

<https://git-scm.com/download/win>

验证：
```powershell
git --version
```

### 2. .NET SDK 9.0

⚠️ **必须装 SDK，不能只装 Runtime。** 只有 Runtime 能跑、不能编译。

<https://dotnet.microsoft.com/download/dotnet/9.0>
（选 **SDK x64**，不是 "ASP.NET Core Runtime" / ".NET Runtime"）

验证：
```powershell
dotnet --list-sdks
# 输出里必须有一行 9.x.x
```

### 3. Godot 4.7.1 —— ⚠️ 必须是 **.NET (mono) 版**

<https://godotengine.org/download/windows/>

页面上有**两个**下载按钮，选带 **.NET** 的那个：

```
❌ Godot Engine            ← 标准版，跑不了 C# 项目
✅ Godot Engine - .NET     ← 要这个
```

或者直接下 GitHub release（文件名里带 `mono`）：
```
Godot_v4.7.1-stable_mono_win64.zip
```

> **为什么版本必须对**：`GunfireDungeon.csproj` 第一行是
> `<Project Sdk="Godot.NET.Sdk/4.7.1">`。
> 用别的 Godot 版本打开，它会**自动改掉这个版本号** —— 版本号一改就是一次 diff，
> 而且不同 Godot 版本的 API 有细微差异，可能编译报错。
> **装同一个 4.7.1 最省事。**

### 4. IDE（可选，但强烈建议）

| IDE | 说明 |
|---|---|
| **JetBrains Rider** | Godot C# 支持最好（有官方 Godot 插件）|
| **VS Code** + C# Dev Kit | 免费，够用 |
| Visual Studio 2022 | 要勾选「.NET 桌面开发」|

用 Godot 编辑器本身也能改代码，但没补全。

## 二、装完后的步骤

### 第 1 步：克隆仓库

```powershell
git clone https://github.com/AssassinHLQ/GunfireDungeon-Mod.git
cd GunfireDungeon-Mod
```

> 仓库有两个 remote：
> - `origin` → `AssassinHLQ/GunfireDungeon-Mod`（**你自己这个修改版**）
> - `upstream` → `xlljc/GunfireDungeon`（原项目）
>
> clone origin 就行。仓库约 **130 MB**，工作区展开后约 **290 MB**，慢是正常的。

### 第 2 步：用 Godot 打开工程

Godot → **Import** → 选：

```
GunfireDungeon-Mod/GunfireDungeon_Godot/project.godot
```

> **第一次打开会卡几分钟** —— Godot 要重新生成 `.godot/` 导入缓存
> （`.godot/` 被 gitignore 了，不会从仓库来，是正常的）。
> 期间进度条可能不动，别关。

### 第 3 步：编译

Godot 打开后按 **Build**（右上角锤子图标），或者命令行：

```powershell
dotnet build GunfireDungeon_Godot/GunfireDungeon.csproj -c Debug
```

**正常结果：`0 个错误 / 37 个警告`**（那 37 个警告是上游遗留的，不用管）。

### 第 4 步：补素材（⚠️ 别跳过，见下一节）

## 三、⚠️ 三个坑（换电脑最容易踩的）

### 坑 1：**有 52 个 PNG 不在仓库里** —— 必须手动补

因为素材授权写着「禁止再分发」，这些图**故意没进公开仓库**，
只在打包发行时打进 pck。新电脑 `git clone` 下来是**缺图**的。

**缺的是这三批：**

| 缺什么 | 多少个 | 不补会怎样 |
|---|---|---|
| 主菜单随机背景（9 套分层）| 49 张 | 主菜单**自动退回**视差大厅背景（有兜底，不崩）|
| AK47 武器贴图 | 1 张 | 武器池里有 AK47，但**画不出来** |
| 不死刽子手 + 幽灵精灵图 | 11 张 | 精英怪会进随机池，但**画不出来** |

**三个还原脚本已经在仓库里**（`git clone` 就有了）：

```powershell
cd GunfireDungeon_Godot
powershell -ExecutionPolicy Bypass -File resource/sprite/ui/mainBackground/variants/restore_variants.ps1
powershell -ExecutionPolicy Bypass -File resource/sprite/weapon/weapon0047/restore_ak47.ps1
powershell -ExecutionPolicy Bypass -File resource/sprite/role/executioner0001/restore_sprites.ps1
```

#### ❗ 但这三个脚本**默认路径写死了**

它们默认从这台机器的这个位置读原始素材：

```
C:\Users\WY157\Desktop\GODOT\可用素材_待接入\✅_明确可用_itch与爱给网\
```

**新电脑上这个目录不存在**（用户名不一样）。两个办法：

**办法 A（推荐）：把素材目录一起拷过去，并保持同样的路径**

需要拷的（都在 `可用素材_待接入\✅_明确可用_itch与爱给网\` 下）：

```
New free backgrounds part1/
New free backgrounds part2/
New free backgrounds part3/
New free backgrounds part4/
New free backgrounds part5/
Free-Guns-Icon-32x32-Pixel-Pack/
Undead executioner/
```

> 这几批都是免费素材，**用你自己的账号重新下也一样** —— 脚本只需要里面的原图。

**办法 B：用参数指定路径**

三个脚本都支持传参：

```powershell
# 主菜单背景（读整个 ✅ 目录）
... restore_variants.ps1 -SourceRoot "D:\素材\✅_明确可用_itch与爱给网"

# AK47（读那张 32x32 图标）
... restore_ak47.ps1 -SourceIcon "D:\素材\...\1 Icons\Icon29_37.png"

# 刽子手（读 png 目录）
... restore_sprites.ps1 -SourceDir "D:\素材\...\Undead executioner puppet\png"
```

补完素材后**再让 Godot 导入一次**（编辑器开着的话，切回窗口会自动导入）。

### 坑 2：**别提交 `.godot/`**

`.godot/` 是 Godot 的导入缓存（几百 MB），**已经在 `.gitignore` 里**。
新电脑会自己重建，不要手动拷、更不要提交。

同样被忽略的还有：
- `GameSave.json` / `GameConfig.json` —— 你的存档和设置
- `excelTool/bin`、`excelTool/obj`、`excelTool/publish`
- `android/` —— 安卓导出产物

### 坑 3：**`Aspose.Cells` 只在导出配置表时需要**

`excelTool/ExcelTool.csproj` 引用了 `Aspose.Cells 23.12.0`（**商业库**）。
它只在「从 xlsx 重新生成 config json」时用 —— **日常开发完全用不到**，
而且主工程的 csproj 里已经把它排除了：

```xml
<Compile Remove="excelTool\**" />
```

**所以你不用管它。** 只有真要重跑配置表导出时才需要，
那时 NuGet 会自动下载（但 Aspose 免费版有行数限制）。

> 更重要的提醒：**重跑导出会抹掉只存在于 json 里的内容**
> （AK47、不死刽子手、邪恶法师、BOSS、BGM 条目…）。
> 详见 `docs/配置表说明.md` §2。

## 五、想「直接拷工作区」而不走 git 的话

如果两台电脑都是你自己的、不想重新配，**整个目录拷过去也能用**，但要注意：

| 要拷 | 不一定要拷 |
|---|---|
| `GunfireDungeon\`（整个仓库，含 `.git`）| `.godot\`（新机器会重建，但拷过去能省一次导入等待）|
| `GODOT\可用素材_待接入\✅_明确可用_itch与爱给网\` | `GODOT\_art\` 等草稿目录（体积大，非必需）|
| Godot 编辑器整个目录（想版本完全一致时）| `*.log`（Godot 日志，本机跑久了能涨到几百 MB）|

## 六、日常开发命令

```powershell
# 编译
dotnet build GunfireDungeon_Godot/GunfireDungeon.csproj -c Debug

# 无头导入（改了资源后）
& "D:\SOFTWARE\Godot-4.7.1-dotnet\...\Godot_v4.7.1-stable_mono_win64_console.exe" `
  --headless --import --path GunfireDungeon_Godot

# 无头启动自检（不用开窗口，能看出有没有报错）
& "..." --headless --quit-after 200 --path GunfireDungeon_Godot
# 期望输出只有 4 行: 版本号 / 随机种子 / 两条退出时的清理提示（这是既有的，不是 bug）

# 提交推送（GitHub 在国内经常抽风，失败就重试几次）
git add -A ; git commit -m "..." ; git push origin HEAD
```
