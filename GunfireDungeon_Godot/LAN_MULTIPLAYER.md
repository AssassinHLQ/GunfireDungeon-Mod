# 局域网联机使用说明

已在项目中加入基于 Godot ENet 的局域网联机功能，默认最多 4 人，端口为 `24567`。

## 联机步骤

1. 两台电脑连接同一个局域网（同一路由器或同一热点）。
2. 启动游戏，进入主菜单，点击「局域网联机」。
3. 房主点击「创建房间」，然后正常进入大厅。
4. 玩家点击「局域网联机」，在「房主 IP」里输入房主电脑的局域网 IPv4 地址，例如 `192.168.1.23`，点击「加入房间」。
5. 房主进入大厅入口后，所有玩家会自动生成同一张地牢地图。

## 查看房主 IP（Windows）

在房主电脑运行：

```powershell
ipconfig
```

填写正在使用的 Wi-Fi 或以太网适配器的 IPv4 地址。不要填写 `127.0.0.1`，除非两端在同一台电脑上测试。

## 防火墙

如果其他电脑连接失败，请允许游戏通过 Windows Defender 防火墙，或放行 UDP 端口 `24567`。不同网络配置可能还需要把当前网络设置为“专用网络”。

## 当前同步范围

- 房主统一决定进入地牢、楼层切换和地牢随机种子。
- 每个客户端同步自己的玩家位置、朝向和移动动画。
- 客户端会自动跟随房主的大厅/地牢状态。
- 原有单机流程不受影响。

当前版本保留了原游戏的大部分本地战斗逻辑；多人战斗中的敌人血量、掉落、伤害和互动尚未做完整的服务器权威化。建议先用于局域网协作试玩，后续再继续补齐战斗同步。
